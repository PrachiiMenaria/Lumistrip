## 🌟 About LumiStrip

**LumiStrip** is a highly interactive, beautifully crafted digital photo studio. Built for Gen Z creators and scrapbooking enthusiasts, it allows users to upload their memories and instantly wrap them in high-quality, aesthetic formats. 

From Y2K cyber backgrounds and dark floral scrapbook pages, to functioning "Spotify" player templates and vintage CVS receipts, LumiStrip turns standard camera rolls into curated works of art.

## ✨ Features

- **🎨 The Decorate Studio**: Drag and drop interactive stickers, stamps, and tape directly onto your photos.
- **🖼️ Frame Gallery**: 20+ mathematically perfect A4 poster frames (including Vogue covers, Film Strips, Kawaii Clouds, and Polaroid stacks).
- **🌈 Aesthetic Filters**: 25 lightning-fast CSS overlay filters to give your photos the perfect vintage, cinematic, or retro vibe.
- **📓 Memory Styles**: 21 complex HTML/CSS graphic templates (Receipts, Music Players, Passports) complete with custom editable text fields.
- **💾 One-Click Export**: Save your customized aesthetic memories instantly in high resolution.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Exporting**: html-to-image

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/PrachiiMenaria/Lumistrip.git
   cd lumistrip
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the magic.

## 📸 Deployment

LumiStrip is fully optimized and ready for production. The easiest way to deploy your own version is by importing the repository into [Vercel](https://vercel.com/new).
